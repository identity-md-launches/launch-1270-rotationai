# Image generation prompts

All artwork was drawn with the built-in `image_gen` tool (gpt-image). No SVG or code-drawn fallback was used. The creator's supplied image was a visual reference; the second geometric pass used the first generated geometric draft as an edit target. Mechanical PNG resampling to 1024×1024 is the only code transformation of the five option files. The selected original generated PNG is copied unchanged to `artifacts/logo.png`.
